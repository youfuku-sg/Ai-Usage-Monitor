# Proposal: remove-7d-status

## 概要

タスクバーウィジェットおよびツールチップに表示されている 7d（7日間ウィンドウ）ステータスを削除する。

## 背景・動機

現在のウィジェットには 5h バーと 7d バーの2行が表示されているが、7d の情報は実用上の優先度が低く、表示がごちゃつく原因になっている。5h のみに絞ることでUIをシンプルにする。

## ゴール

1. ウィジェットから 7d バー・テキスト行を削除し、5h のみ表示する
2. ツールチップから 7d の情報を削除する
3. API レスポンスの `seven_day` フィールドのパースを削除する

## スコープ外

- 5h 表示の変更
- Codex の表示に関する変更
- API リクエスト自体の変更（エンドポイントはそのまま）
