# Proposal: claude-single-line

## 概要

ウィジェットの Claude Code 表示を 5h の 1 行のみにする。

## 背景・動機

現在 5h・7d の 2 行が表示されているが、`remove-7d-status` で 7d を削除することで自然に 1 行になる。本チェンジはその結果として Claude Code が 1 行に収まることを確認・整理するためのものであり、`remove-7d-status` の完了後に実施する。

## ゴール

- ウィジェットに Claude Code の 5h 情報のみが 1 行で表示されること
- 不要な余白・レイアウト崩れがないこと

## 依存

- `remove-7d-status` が完了していること

## スコープ外

- 表示フォーマット（ラベル・時刻形式）の変更（別チェンジで対応）
- Codex の追加（別チェンジで対応）
