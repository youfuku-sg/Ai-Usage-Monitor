# Proposal: add-codex-line

## 概要

ウィジェットの 2 行目に Codex の使用量を表示する。

## 背景・動機

Claude Code に加え Codex も日常的に利用するため、同じウィジェットで残使用量を確認できるようにする。

## ゴール

- ウィジェット 2 行目に `codex: {使用率}% · {HH:MM}` を表示する
- 表示するのは数時間単位のウィンドウのみ（7d 相当は表示しない）
- 行頭ラベルは `codex:` とし、claude: と縦位置を揃える
- Codex にアクセスできない（未契約・認証なし等）場合は行を非表示にする

## 依存

- `show-reset-time` が完了していること

## スコープ外

- Codex の通知機能（閾値アラーム）
- Codex のトレイアイコン追加
