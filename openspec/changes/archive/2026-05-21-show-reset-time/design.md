# Design: show-reset-time

## 変更対象ファイル

### `src/poller.rs` — `format_line()`

リセット時刻をカウントダウンではなく HH:MM 形式で返す。

```rust
// 変更前（カウントダウン例）
"40% · 3h 20m"

// 変更後（実時刻）
"40% · 15:30"
```

リセット時刻は UNIX タイムスタンプで取得できるため、ローカル時刻に変換して `HH:MM` 形式にフォーマットする。

### `src/window.rs`

- ウィジェット描画: `format_line()` の出力をそのまま使用するため変更不要の可能性あり
- ツールチップ: HH:MM 形式を使用するよう更新する

## 実装上の注意

- ローカル時刻変換には `std::time` または軽量な時刻ライブラリを使用する（依存を最小限に）
- リセット時刻が取得できない場合（フォールバック時）は `--:--` を表示する
