## Context

README.md はリポジトリの顔であり、GitHub にも公開される唯一のドキュメントファイル。  
フォーク元の内容が残ったままで、プロジェクト名・機能・インストール手順がすべて実態と異なる。  
ソースコードの変更は一切不要で、README.md の書き直しのみで完結する。

## Goals / Non-Goals

**Goals:**
- AiPulseHub の実際の機能・仕様を正確に記載する
- 日本語で統一し、個人利用プロジェクトとして適切な粒度で書く
- GitHub に公開されても問題ない内容にする

**Non-Goals:**
- 英語版の並記
- スクリーンショット・アニメーション GIF の差し替え（素材未準備）
- API エンドポイントの詳細リファレンス（別ドキュメントで対応）

## Decisions

### README の構成

フォーク元の構成を参考にしつつ、AiPulseHub の特徴である「REST API 配信」「閾値通知」を前面に出す。

```
# AiPulseHub
バッジ（platform / license）

概要（1〜2文）

## 機能
## 動作環境
## インストール
## 使い方
  ### タスクトレイ
  ### タスクバーウィジェット
  ### REST API
  ### 通知
## 設定
## プライバシーとセキュリティ
## ライセンス
```

### 画像・GIF の扱い

現状はフォーク元の `.github/animation.gif` が参照されているが、AiPulseHub のものは未準備。  
今回は画像セクションを省略し、スクリーンショットが用意できたタイミングで別 change で追加する。

### インストール手順

WinGet は使用しない。GitHub Releases からの exe 直接ダウンロードのみを案内する。

## Risks / Trade-offs

- 日本語 README は日本語話者以外には読めない  
  → 個人利用プロジェクトのため許容する。将来 OSS 公開時に英語版を追加する

- スクリーンショットなしだと視覚的に伝わりにくい  
  → 機能説明のテキストで補う。画像は別 change で対応
