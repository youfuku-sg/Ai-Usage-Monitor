# Proposal: per-machine-install

## 概要

MSI インストーラーを per-machine（全ユーザー）インストールに変更し、「アプリと機能」への表示と半自動更新（MSI 再実行方式）を実現する。

## 背景・動機

現在の perUser インストールでは Windows の「アプリと機能」（Settings > Apps）に表示されず、アンインストールが分かりにくい。また、exe の自動自己置換による更新はユーザーの意図しないタイミングで適用される。

per-machine に変更することで：
- 「アプリと機能」に表示され、通常のアプリと同じ手順でアンインストールできる
- 更新時に UAC プロンプトが出るため、ユーザーが意図的に承認してから適用される（半自動）

## ゴール

1. MSI を per-machine インストールに変更する（インストール先: `%ProgramFiles%\AiUsageMonitor\`）
2. 「アプリと機能」に表示されるようにする
3. 自動更新の仕組みを「新 MSI をダウンロードして実行（UAC 経由）」に変更する

## スコープ外

- ポータブル版（exe）の更新方式変更（exe 自己置換のままでよい）
- コード署名
