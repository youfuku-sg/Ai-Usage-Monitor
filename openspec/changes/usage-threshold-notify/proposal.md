# Proposal: usage-threshold-notify

## 概要

Claude Code の使用率が設定した閾値（80%・90%・95%・98%）に達したとき、Windows トースト通知（バルーン通知）を送出する。

## 背景・動機

現在の通知機能は認証エラー時のみ動作する。使用量制限の到達を事前に知らせる仕組みがないため、気づかないうちに上限に達してしまう。要求定義書の REQ-NOTIFY-001〜004 として要求が定義されている。

## ゴール

1. 使用率が閾値（デフォルト: 80% / 90% / 95% / 98%）に達したとき、トースト通知を送出する
2. 同一の 5h ウィンドウ内では同じ閾値の通知を1回のみ送出する（ウィンドウリセット後はリセット）
3. 通知には対象サービス名・使用率・リセット予定時刻（HH:MM）を含める
4. 閾値は設定ファイルで変更できる

## スコープ外

- Codex の閾値通知（将来の `add-codex-line` 完了後に拡張）
- 通知の UI カスタマイズ（アイコン・サウンドの変更）
