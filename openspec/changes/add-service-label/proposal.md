# Proposal: add-service-label

## 概要

ウィジェットの各サービス行の先頭に `claude:` のようなサービスラベルを追加する。

## 背景・動機

将来的に複数サービス（Claude・Codex 等）が並ぶため、どの行がどのサービスかを一目で識別できるようにラベルを付ける。

## ゴール

- ウィジェットの Claude Code 行の先頭に `claude:` を表示する
- ラベルは固定幅で揃える（Codex 追加時に縦位置が揃うよう）

## 依存

- `claude-single-line` が完了していること

## スコープ外

- Codex のラベル（`codex:` の追加は別チェンジで対応）
- ラベルの色・フォントの変更
