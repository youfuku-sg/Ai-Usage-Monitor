# Proposal: add-installer

## 概要

現在ポータブル exe（単体ダウンロード）のみで配布している Ai-Usage-Monitor に、Windows インストーラー形式のパッケージを追加する。

## 背景・動機

ポータブル exe でも自動更新は機能するが、インストーラー形式にすることで以下のメリットが得られる：

- スタートメニュー・デスクトップへのショートカット登録
- 「アプリと機能」からのアンインストール対応
- 配布物として信頼感が増す（インストーラーに慣れたユーザー向け）
- 将来的な WinGet 登録時にインストーラー形式が求められる

## ゴール

1. MSI または exe インストーラーを GitHub Actions でビルドして Releases に含める
2. README にインストーラー版とポータブル版の両方の説明を追加する

## 方針

`cargo-wix` を使って MSI を生成する。理由：

- Rust プロジェクトとの親和性が高い（Cargo に統合）
- WiX Toolset ベースで Windows 標準の MSI を生成
- GitHub Actions での自動ビルドが容易

## スコープ外

- ポータブル版の廃止（両方継続して提供する）
- コード署名（別途対応）
- Microsoft Store 配布
